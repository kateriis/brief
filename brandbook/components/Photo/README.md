Фото Катерини — один кадр у двох обробках.

- Перший екран (`kk-photo--warm` з `photo-intro.webp`): колір, повний кадр, без фільтрів.
- Фінал і подяки (`kk-photo--warm` з `portrait.jpg`): колір, повний кадр.
- Строга (`kk-photo--strict`): ч/б, контраст 1,1, збільшення 1,4 з центром на обличчі — лише для «про мене» і строгих носіїв.
- Рамка 4:5 (на мобільному 1:1), кути `radius-lg`. Підпис: ім’я стилем `eyebrow`, роль — `caption` кольору `ink-50`, над ними лінія `line`.
- Поки фото немає, рамка показує `accent` — під неї ставте монограму «КК» білим.
