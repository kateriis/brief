Поле для відповіді: питання, підказка, саме поле і, за потреби, повідомлення про помилку.

- Питання — стиль `question`; обов’язкове позначайте зірочкою `ink-50`.
- Підказка — стиль `body` кольору `ink-50`: пояснення людською мовою з прикладом.
- Поле — `surface`, кути `radius-md`, без рамки; текст стилем `input` (не менше 16px). Довге поле росте разом із текстом, без внутрішньої прокрутки.
- Фокус — рамка `ink`. Помилка — рамка `error`, заливка `error-bg` і текст `error` під полем, який каже, що зробити.
- Ширина колонки з полями — не більше `field-max`.
