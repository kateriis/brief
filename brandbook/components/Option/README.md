Варіант відповіді — картка з квадратиком (кілька варіантів) або кружечком (один варіант).

- Заливка `surface`, кути `radius-md`, відступ між картками `space-2`.
- Вибраний — рамка `ink`, позначка зафарбована `ink` з білою галочкою чи крапкою.
- На десктопі — дві колонки, на мобільному — одна.
- Варіант «Інше» відкриває під списком поле для свого тексту на всю ширину.
