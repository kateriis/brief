Кнопка складається з двох блоків — підпису і квадрата зі стрілкою — з відступом 2px між ними.

- Головна (`ink`, білий текст) — одна на екран: ДАЛІ, НАДІСЛАТИ БРИФ, НАПИСАТИ В TELEGRAM.
- Другорядна (`surface`, текст `ink`) — для «Назад» і допоміжних дій; квадрат зі стрілкою можна прибрати, якщо дія не веде далі.
- Підпис — стиль `button`: Inter Tight Medium, великі літери, дієслово дії.
- Висота `button-h`, кути `radius-md`. При наведенні стрілка зсувається на 3px у бік дії.
- На мобільному головна кнопка розтягується на всю ширину, «Назад» лишається квадратом зі стрілкою.
- Не робіть кнопки бордовими, обведеними чи «пігулками».
